# Дипломная работа. Часть 2. Задание 3. Автотесты UI
Проект тестирования веб-приложения [Stellar Burger](https://stellarburgers.education-services.ru/)

## Технологии
- IntelliJ IDEA 2025.2.4
- JDK corretto-11.0.28
- Build System Maven 3.9.11
- JUnit 4.13.2
- Allure 2.15.0
- RestAssured 5.5.5
- Selenium 4.38.0

## Параметры проекта и постоянные тестовые данные
Файл [resource.properties](src/test/java/config/resource.properties)

## Тестовые сценарии
1. **Регистрация**
   - Успешная регистрация.
   - Ошибка для некорректного пароля. Минимальный пароль — шесть символов.

2. **Вход**
   - вход по кнопке «Войти в аккаунт» на главной;
   - вход через кнопку «Личный кабинет»;
   - вход через кнопку в форме регистрации;
   - вход через кнопку в форме восстановления пароля.

3. **Раздел «Конструктор»**
   - переход к разделу «Булки»;
   - переход к разделу «Соусы»;
   - переход к разделу «Начинки».

## Запуск тестов
```shell
mvn clean test
```
## Подготовка отчета
```shell
mnv allure:serve
```
